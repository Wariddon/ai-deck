# Receive review

## Evidence reply

Answer the named criterion first. Check the concrete claim against this checkout or cite an observed result. If the available evidence cannot settle it, name the remaining gap in one sentence. Keep the worktree read-only.

## Repair

Verify the finding against the current checkout before changing it. Fix the affected behavior within the assigned paths. If the finding does not hold, cite the counterevidence. Report the changed evidence against the original criterion ID.
